Prioridad 1 — Criticas (bloquean generacion de leads)

UX

Optimizar galeria de fotos en fichas de inmueble

Alto Medio

El carrusel genera 794 clicks/sesion frustrada. Botones no responden durante carga.

Implementacion:

  • Lazy loading con placeholder blur (LQIP) para imagenes
  • Skeleton loader mientras carga siguiente imagen
  • Precargar imagen N+1 mientras ve imagen N
  • Disabled state visual en botones durante transicion
  • Soporte gestos swipe en mobile
H1: Visibilidad estado H4: Consistencia Doherty: <400ms
UX

CTA flotante "Agendar visita" en fichas

Alto Bajo

65% no llega al CTA (scroll 35% promedio). Boton de contacto invisible para la mayoria.

Implementacion:

  • Sticky bar inferior (mobile) con precio + CTA
  • Mostrar tras scroll pasado el hero/galeria
  • A/B test: sticky bar vs boton flotante circular
Fitts: Reducir distancia H6: Reconocer vs recordar
Tech

Reducir LCP Home mobile: 10.8s a <2.5s

Alto Medio

LCP 8.3x peor en mobile vs desktop. Imagen hero no optimizada para mobile.

Implementacion:

  • Imagenes responsivas con srcset (WebP/AVIF para mobile)
  • Preload del LCP element
  • Eliminar 279 KiB de JS sin usar
  • Eliminar 124 KiB de CSS sin usar
  • Critical CSS inline para above-the-fold
LCP target: <2.5s Score actual: 55
Tech

Reducir TBT Arriendo mobile: 830ms a <200ms

Alto Alto

Hilo principal bloqueado ~1s. Usuarios no pueden usar filtros ni tarjetas.

Implementacion:

  • Code splitting: solo JS para above-the-fold
  • Defer scripts terceros (analytics, ads, chat)
  • Reducir 222 KiB JS sin usar
  • Tree shaking agresivo en bundle Angular
TBT target: <200ms H7: Eficiencia de uso

Prioridad 2 — Importantes (mejoran UX y engagement)

UX

Subir "Inmuebles similares" arriba del fold

Cross-selling invisible (scroll 65%+). Mover como carrusel horizontal despues del precio.

Ley de Miller H8: Diseno minimalista
UX

Feedback inmediato en filtros de listados

Dead clicks en filtros: no dan feedback visual. Agregar loading state + contador de resultados en tiempo real.

H1: Visibilidad del estado Ley de Jakob
Tech

Corregir CLS 0.106 en listados

Layout shift visible al cargar tarjetas. Reservar espacio con aspect-ratio y dimensiones explicitas en imagenes.

CLS target: <0.1

Prioridad 3 — Quick wins de performance

Tech

Eliminar CSS sin usar (~106-124 KiB por pagina)

PurgeCSS o Tailwind purge. Impacto en FCP y Speed Index.

Tech

Imagenes en formato moderno (WebP/AVIF)

Reduccion 30-50% en peso. Impacto directo en LCP mobile. Usar picture con fallback.

Tech

Preconnect a dominios de terceros

Agregar preconnect hints para CDN, APIs y tracking. Ahorra ~100-300ms por recurso.

Prioridad 4 — Oportunidades (SEO + Accesibilidad)

SEO

Mobile-first: cerrar brecha mobile vs desktop

Google indexa mobile-first. Score desktop 96-100 pero mobile 55-85. Mobile ES la experiencia SEO.

A11y

Accesibilidad del carrusel de imagenes

Verificar ARIA labels, alt text en imagenes de inmuebles, navegacion por teclado del carrusel.
